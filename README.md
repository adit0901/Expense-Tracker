# FinTrack

Personal finance and wealth management platform (INR-first). Modular monolith:
React + TypeScript frontend, FastAPI backend, PostgreSQL.

> Status: P0 – Core MVP in progress (see `openspec/changes/fintrack-p0-core-mvp`).

## Repository layout

```
frontend/        React + Vite app
backend/         FastAPI app (app/, alembic/, tests/)
infrastructure/  Dockerfiles, nginx config
docs/            Architecture, calculations, runbook
openspec/        Specs and changes
scripts/         Local development helpers
```
